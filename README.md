<div align="center">
  <h1>OKERA-OKE</h1>
  <p>Karaoke and music-video player built with React.js, Tailwind CSS, React Router, and Redux Toolkit.</p>
  <p>YouTube browsing and video playback are intentionally retained.</p>
</div>

## Features

- Browse and watch YouTube videos
- Search for videos and music
- Open video watch pages and view comments
- Responsive interface
- React Router navigation and Redux Toolkit state management

## Getting Started

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm start`.
4. Open `http://localhost:3000`.

## Production Build

Run `npm run build` to create the production build.

## Project Identity

The app is branded as **OKERA-OKE**. YouTube video search, browsing, and playback functionality from the original project should remain enabled.
